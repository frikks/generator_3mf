# 0.1.0

First release / Первый выпуск.

- Bins: 1–8 × 1–8 units, 2–18u height, up to 8 × 8 compartments, stacking lip, magnet pockets, scoop, label ledge, M3 screw holes, wall 0.8–2.4 mm.
- Baseplates: 1–8 × 1–8 units, optional magnet floor.
- Export to 3MF (with colour) and binary STL; meshes are closed and manifold.
- Live 3D preview, presets.
- Themes: Classic, Light, Dark, AMOLED. Languages: English, Русский.
- Builds: Windows `.exe`, Android `.apk`, single-file `.html` (works offline).
